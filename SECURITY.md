# Security Policy

This project is a public, synthetic example for metadata-driven lakehouse ingestion validation.

## Data and confidentiality requirements

Do not submit any of the following in issues, pull requests, examples, or tests:
- Secrets, keys, tokens, credentials, or connection strings
- Client or production data
- Production configuration files
- Confidential architecture details from private systems

Use only synthetic and generic examples.

## Reporting a security issue

Please open a private security report through GitHub Security Advisories if possible, or open an issue with minimal details and request secure follow-up.
